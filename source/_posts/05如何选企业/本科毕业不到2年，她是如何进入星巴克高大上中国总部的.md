**第一份工作**

**说**起“团子”，实际上是一个东北女孩，94年的，目前在星巴克做会计。

# 【南下】

团子实际上是她的网名，她2015年夏天毕业后，就直奔上海来求职了。此间，她加了上海地区的很多求职QQ群，我就是在其中一个群里认识团子的。我们都知道，东北是三个省，大家问团子来自哪个省，她却古怪精灵，一会说家乡在吉林，一会儿又说她来自哈尔滨，有时碰到男孩问她又自称上海姑娘。

在2015年七八月份，花了两三个月只身闯上海求职后，团子中意的一家火锅连锁店没要她，月薪才4500，却意外收到一家世界五百强的Offer，月薪5000。更意外的是，这五百强面试她都没问她英语，就中文聊天，面试成功了。这可真是意外，不然团子这东北英语可得露馅儿，高中和大学期间她就英语最差。

![Image](https://mmbiz.qpic.cn/mmbiz_jpg/t5Q7hjE2iasoyZudMQFzGcSGXHfXmyzYUia1hiauABicdr2Y0tCcP4aeFW9OEpORibibV2wsBIlUNu6TbZKib6IjGoHZw/640?wx_fmt=jpeg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=1)

# 【首次就业】

这五百强叫林德，是一家亚洲总部位于上海浦东的**德国公司**，王珞丹的《杜拉拉升职记》就几乎全程在这公司取景的。建在闹市区的拐角处一个天鹅湖上，旁边是水上旋转餐厅。

![Image]()

团子的工作岗位是AP（应付账款），尽管并不喜欢会计专业也不喜欢会计工作，但她的未来抱负仍然是沿着财务职业道路，想往财务分析方向发展，希望尽快成为CFO。团子还是蛮上进的，一入职就开始了CPA的孤独征途。

![Image]()

# 【白领生活】

公司确实人性化，午餐也不错，免费的，团子很喜欢。每周还有瑜伽课，公司给员工报名的，可以用周五中午和下午的工作时间去学瑜伽。

![Image]()

领导也不错，50来岁的一个女经理，和蔼可亲，团子犯错多次，领导总是笑嘻嘻教导她，从不责备。

第一份工作，就遇到这么好的领导，美女团子很开心，要么就在这多干几年？

![Image]()

此间团子一个人租了附近的房子住，母亲不放心，从东北赶来“陪工”了好几个月。

尽管2015年的CPA科目全挂了，但团子充满干劲。她性格活泼开朗，有点古怪精灵，很乐观，春节假期回来后，还领养了一只猫。这就是她想要的外企白领生活，她就是杜拉拉。

# 【明天可以不来了】

正当团子沉浸在白领练瑜伽之际，2016年5月份的某天，刚上班，HR过来发了个书面通知给她，说合同到期，明天可以不来上班了。公司比较人性化，补贴给她1万元，相当于两个月的工资。

团子直接懵逼了，她哪知道怎么回事，她也不懂得啥合同，只是入职时签了字而已。

![Image]()

此时，团子在QQ群里紧急找到了我，问“如何是好？”

我说，你找下你签的劳动合同，看下日期。

她说，之前没注意看，现在才发现是个短期合同，才10个月的雇佣时间，尽管不是第三方合同而是跟这家五百强直接签的。

我说：“你问下领导看看。”

她说：“问了！领导说完全不知道，还准备重用我呢！”

![Image]()

事已至此，我让团子尽快找工作，多投点简历。

# 【5600份简历】

团子当天晚上疯了似的，给我发了很多信息，说50岁女领导原来是笑里藏刀，枉她平时还对这领导尊敬有加。说着说着，团子就将这女领导的微信直接删了，屏蔽，加入黑名单！

东北姑娘还是比较要强的，也就经过一晚的折腾，第二天她就在前程无忧上投出去了几百份简历。

原来每投一份简历，系统都会提醒“您可能会对如下职位感兴趣”，果然是大数据，团子看到这些职位相仿，也投递了。一开始还挑下，后来就直接“全选”，全部投递简历。第三天，又上了智联等其他招聘网站，如法炮制，反正只要跟“会计”二字相关的职位，全部投递。后来团子自己说，一周内总计投递出去5600份简历。

![Image]()

# 【迅速再就业】

乖乖，这海投的猛烈程度，恒古绝今，到底是东北姑娘。

但海投还是有效果的，接下来一周面试电话不断。团子就通过一周内四五家的面试，获得俩录取意向，直接挑选一家，上班去了！

# 【第一份工作的小结】

整个这一年，我们看到东北美女直接放弃了校招，一毕业就来到一线城市，通过海投成功求职。说明应届生通过社招也是容易就业的，因此，如果你校招没遇到好的单位，别害怕，后面有的是机会。

同样，我们也看到，海投简历在换工作过程中还是有用的，尤其是毕业头几年，差不多一两周就能重新就业，工资还会上涨一点，尽管突然碰到了上家合同不续签、被裁员的情况。

此外，英语不好也可以进外企，尤其是职场初期，岗位级别都不高，你能碰到外国人直接面试你的可能性极低，并且中国主管也大多并不测试你的英语，甚至怕你万一比TA英语还要溜，TA不是出洋相了？！

**第二份工作**

**东**北美女团子，毕业一年，刚刚通过海投简历在上海找到了新工作。

这新东家不错，**月薪6千**，比上一家德国企业多了1千，是一家美国奢侈品公司，类似Prada的档次。

![Image]()

# 【外企老司机】

外企看来都差不多，一上班，团子感觉**熟门熟路**，之前毕竟有过十来个月的500强工作经验。

刚报到，发现新公司到底做奢侈品的，连免费的午餐都比上家还要好，美食种类全，更精致，大中午的像在五星级酒店吃精选自助餐一样。团子比较好吃，特别看重公司的午餐，对，以后就以午餐好坏来挑公司！

![Image]()

# 【背景调查？】

上班第二周，HR突然来找团子，要她填写背景调查资料。啥“背景调查？”“还要填写上家领导的姓名和联系方式？”团子懵了，不情愿地填好后，赶紧将前领导在微信上解锁。不得了，看来职场上不能得罪人，坏人你也要善待TA。

# 【批斗会】

尽管工作也是个**应付款小会计**跟上家一样，但团子还是频繁出错，三个月刚转正，她又出纰漏了，提前付款给了供应商，金额还不小，几十万。目前的女领导比上家的“老女人”年轻点，刚过40岁，孩子也才1岁。无论如何，这次得注意观察下，被再跟上家一样，又被女领导忽悠了，**当面教导总比笑里藏刀好**！

就小了这10岁，区别怎么就这么大呢？她将团子狠狠训了一顿。但，领导也没办法，自己招的人含着泪也要继续用，只不过从今开始，领导要每周跟团子单独开会聊天一次，时间定在每周二下午2:00。领导苦口婆心，让团子要工作上心，刚毕业就得主动，知错就改，要团子向她学习，将来才能做领导。

![Image]()

可惜，团子94年的，目前才23岁不到，她总感觉领导这每周的谈话，就是单独针对她的一对一批斗大会。每周一上班，就浑身不自在，因为明天有个批斗大会。那种感觉，真是生不如死。

此间40岁女领导多次申请加她微信好友，团子死活不加，就当做没看到。

![Image]()

# 【走为上】

此时，正是2016年国庆后，团子又找到了我，火急火燎的，问咋跳槽。我正好有个职场朋友圈的周末聚会，就请她也参加了。

聚会期间，团子跟我说转正后的这两三个月她已经出去面试了，专门找公司附近离得不远的公司，这样才好上班时间偷偷溜出去面。我觉得好笑，一个小姑娘的古怪精灵和小心思，展露无疑，我给她讲了点职场大道理。

【爱情来了？】

聚会回去后，倒有一段时间没听说团子继续跳槽的事，因为她通过我组织的那次聚会，跟一个同样94年的小伙子张翔**谈起了恋爱**。

张翔也不错，来自昆明，数据分析工程师，蛮有想法的，还准备以后创业。

![Image]()

# 【求职碰壁】

2017元旦过后，团子突然又冒出来了，信息狂轰滥炸过来，说自己这期间面试了好几个公司，没一个成功的：包括一个做设备的五百强公司丹纳赫，只是个小事业部的小工厂，还偏，居然面试了没回音；有家叫做霍尼韦尔，还中国总部的，8幢楼，以为是高大上公司，虚有其表，连公司前台的沙发都破的，月薪只愿意给她6000，多一分都不行。

![Image]()

# 【意外的面试，要不要去？】

我说，“你不是已经会猛投简历了嘛，继续多多投递。”

果然某天早上来了信息，“幽哥，昨天下午有个做咖啡的外企让我去面试，我都没准备，也没请假，不想去了。”

“是星巴克吧？”

团子回道：“是的，是星巴克总部。”

我看她捉急，开个玩笑：“我不知道怎么弄，你问你男朋友。”

“他知道个屁，他自己还在到处面试呢，最近去贵州出差去了。再说他也不懂。”

我不开玩笑了，“赶紧去，星巴克多么好的公司！找工作就是要找这种上升期的公司，新职位多，加薪晋级才多，你不是想做领导嘛。”

“可是，我不知道如何请假啊！”

我哭笑不得，发了个信息给她：“你发短信给领导，就说大姨妈来了，请假半天。”

就这样，那边停止了消息。

![Image]()

# 【柳暗花明】

下午，午饭刚过，来消息了：“我已经去徐家汇面试回来了。”

就这样，一次偶然的机会，甚至都没准备好、已经不想去的面试，成就了团子目前的工作----进入了星巴克中国总部，从此开启了新的事业人生。

![Image]()

# 【第二份工作的小结】

以上，通过东北美女在上海第二份工作历时半年的始末，可见如下几点经验。

1）进了外企后的简历更受外企欢迎，外企也是个圈子；

2）外企的初级职员（比如小会计），也要经历被公司做背景调查；

3）上家领导没必要得罪；

4）即使是五百强，工资也吝啬，尤其是传统行业的公司；

5）面试主管招你进来，“含着泪也会用你”，能容忍你的正常工作失误，并让你转正；

6）本科毕业1年在上海市场价，也就是6千上下的月薪；

7）聚会是最快的谈恋爱方式，比微信加好友靠谱；

8）“加不加领导的微信”，是当今职场的必选题。

**第三份工作**

**2017**年元旦过后，正好是本科毕业一年半，东北美女“团子”开始了在上海的**再次跳槽**。

# 【谈工资】

这不，昨天刚去星巴克总部面试了，第二天，就给我发来了消息，“星巴克还没通知我，也不知道面试会不会看中我。”

“你开价多少？”

“1W，按你说的，好公司得开高工资。”

下班前，团子又来了信息：“星巴克会不会没戏啦？！”

“今天是周五，这才两天，你好歹给人家两三天缓冲下吧，准备Offer也要时间。”

周一上午，要到午饭时间了，信息又来了：“看来没戏了！”

我就发了一个字：“等”。

午饭刚过，那边好消息来了：“幽哥，星巴克给我Offer啦！问我要工资证明，这怎么办？！”

“那就提供呗，拍个工资单照片给HR也行。”

“可是我简历上工资多写了1K啊！”

“傻，就说公司每月工资之外，还发一张1000块的购物卡。”

“哦！”那边的团子恍然大悟。

![Image]()

# 【黑木耳】

拿到星巴克Offer后，团子反而想开了，主动添加了40岁女主管的微信，觉得领导给自己的政治课不是批斗大会，而是对自己好，接下来背景调查可能还要麻烦人家。所以，团子提出离职后，准备加强跟领导的关系，马上就要走了。趁着过年回家，她带过来了很多东北特产，其中，两大包原生黑木耳，她准备送给女领导。”

第二天刚准备送，头天晚上被群友集体制止，“哪有人给40岁女领导送黑木耳的？”

团子想想也对，就没送。

![Image]()

# 【郊区房】

上家奢侈品公司离职，到下家星巴克报到之间，团子凑了个首付，在**靠近上海的郊**区买了一套小房子。看来女孩对房子还是情有独钟的，当然，首付主要是父母卖了东北老家一两套房子凑的。

接下来就是2017年3月，团子开心地去星巴克位于徐家汇的总部报到了。

![Image]()

# 【上升期的公司，就是你的求职风口】

这星巴克，开一家火一家，我觉得咖啡口味也就一般，我个人更喜欢Costa。不过中国人就喜欢星巴克，大多数门店都要排队等候买咖啡。

插播一个细节，肯德基麦当劳是竖着排队的，而星巴克是横着排队的，不信你观察一下，这也是特色。

![Image]()

星巴克计划在中国的门店数量三年内翻番，这就是一个处于持续上升期的公司，团子在中国区总部工作，我跟她说待着，不要走了。这种上升期的公司，是足够承载一个普通白领未来十年二十年甚至更长职业生涯的。

相比较于传统公司，包括那些大多数下行期间关停并转的公司，岗位不断萎缩，星巴克的加薪晋级机会显然更多，连面试都是今天通知明天来，可见**求贤若渴**。果然如此，团子入职才大半年，就享受了一次公司**秋季的年度加薪**。

![Image]()

# 【总部福利】

我们平常只去星巴克门店喝咖啡，却不知道星巴克总部还给员工提供健身房、浴室，每月有员工生日会，每年加薪也有2次以上的机会，还给员工老家的父母买保险。

就在2017这个12月初，马云到访星巴克总部和门店，团子就力争跟马云“马爸爸”的见面机会。可惜她资历尚浅，没排到她。

![Image]()

# 【男友逃之夭夭】

年初进了星巴克后，团子的男朋友也不谈了，不知为啥，难道都说90后的爱情来得快去得快？

我问团子为何不谈了，她说，他小气，不肯发红包！

后来我偶然的机会，问这小伙子，为何不谈了，原来团子问他要两套房子，必须在上海，还要全款买的，不能有贷款。“我的天！”不光是小伙子，连我也叫出来了。

不过随着时间推移，团子的择偶标准也在变化，并且她自己也有了房子，希望以后的男孩不会逃之夭夭。

![Image]()

# 【宠物鼠】

不谈恋爱、不养猫的团子，依旧喜欢小动物，最近开始养宠物鼠。

大家看下，这就是仓鼠，属于女白领爱好的宠物之一。你淘宝上看看，或者百度搜下，原来很多人有这爱好，喜欢养仓鼠。

她自己叫团子，所以自称妈妈，管这只仓鼠叫“小团子”。看来，即将本命年，母爱泛滥了。

![Image]()

# 【经验总结】

**以上就是一个94年的小姑娘，从2015年毕业至今头两年的上海求职记。**

东北姑娘直接放弃了校招，刚毕业就勇闯上海滩，没有经过英文面试也进了外企，还进入奢侈品公司总部一试身手，最后进了高大上的餐饮连锁巨头星巴克的总部。毕业头两年，她是如何在当下的上海活下来的？已经完全呈现。

![Image]()

那么，本科毕业不到2年，她是如何进入星巴克高大上中国总部的？

一，类似经验：之前有外企经验且待的是总部，更容易进其他外企的中国区总部；

二，新东家用人需求多而切：星巴克这样的公司，处于快速扩张期正缺人，当然要到传统行业挖人才能满足人才需求，此时进去难度不高；

三，求职也是一门技术：团子已经历过一次跳槽、两次外企求职，加上海投的经历，此时已经有了一定的求职技巧。

你要问这小会计团子目前月薪多少，有没有1万还是1万5？我也不知道，小姑娘有了2年社会经验，知道保密了。

以上真实经历，分享**团子和星巴克**的故事，与大家共勉，尤其是刚毕业不久或者即将进入一线城市的人们。
