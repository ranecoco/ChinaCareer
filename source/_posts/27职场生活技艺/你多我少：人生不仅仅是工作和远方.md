**职**场人一直工作，反而少了静下来思考的时间。为了不至于将来后悔，我让你几分钟内迅速体验下人生，今天我们欣赏下职场哲理诗​**《你多我少》**​。

人生，除了工作和远方，还有诗。

# **【工资多的回家少】**

最简单的，**程序员**高工资，两三万月薪的也常见，你问他每天几点下班？

过去我们做​**模具工**​，每次客户订单来了，那就得四天连轴转，100个小时也就车间隔壁补几个小时的觉。不过，我们模具工在2000年是月薪到手8000，可以买上海外环内3个平方，是当时的高工资。相比较而言，当今程序猿的高工资才那时模具工购买力的1/15。

购买力先不谈，你就看看你的高薪同学，或者你们那个秃顶的40岁的部长、总监，他工资是比你高3倍，你看他是不是比你忙4倍？！

再到大老板，你问下马云马总一个月回家几天，还有王总，他不但忙得不回家，连儿子也忙得不归家了。

到了你身边，你看看叔叔、阿姨、七大姑八大姨中，工资高的是不是时间最少，照顾长辈时最不上心？大多如此，一看必知。

**工资多的，回家必定少，你心态要放平。**

# **【姿色多的穿衣少】**

姿色多，你不露出来，别人怎么知道呢？无论是明星，还是车模，也无论男女，有身材，有脸蛋，有气质，统称姿色。

有姿色就要露，否则自然是埋没了你的价值。有姿色不用，过期作废。

![Image]()

# **【想法多的成事少】**

这个就更常见了，大学生还没毕业，各种纠结，“我是回老家进事业单位，还是去北上广进高大上企业做白领？”“我如果进了BAT之一2年后，发现华为更好，我是不是可以随时跳槽过去上班？”“我是顺着专业找工作好呢，还是随便找个单位去上班好？”等等，看见了没有？应届生最是​**想得多做得少**​。没办法，年龄限定了思维，这也是人生弯路的必经阶段。

毕业第一份工作就不满意，但迟迟不肯走，也不付出行动，3年后才后悔自己之前没跳槽，**贻误战机**了。

再接着，买个首套房，你有资格，也能凑到首付，结果，​**各种纠结**​，老家买好还是买昆山要么省会郑州？想得太多，自然不能成事，五年之后积蓄剩得只够买厕所，还是​**半个厕所**​。

再接着，35岁不想这么早就中年危机来了，还好自己不至于失业，但工作之外想开拓副业，想投资理财。之前十年也一直想创业，就是没有行动，好不容易在40岁前仨同事合伙创业了，结果前怕狼后怕虎，仨合伙人各种利弊分析，​**还是一事无成，转眼就到了45岁**​。

有道是，“​**秀才造反十年不成**​”，想得太多，成不了事。他们忘记了，事业和人生，都是干出来的，干的同时才知道深浅，才能步步为营。

![Image]()

# **【成事多的寿命少】**

成事多的，长命百岁的确实不多，太折腾，有的放不开，自己思想包袱过重。

2004年我是个小采购员，去温州出差，当地黑车司机很可惜地跟我说，**​“我们这有个大老板，前不久走了。”​**这大老板叫做王均瑶，才38岁，当年公司营业额做到100亿，那是大老板了。这么大的老板，你就放开手让下面的人多参与运营就行，也就是放权即可。可惜，销售出生的他，连每一笔5万块的报价单都亲自审批，你说这能长寿不？

其他所谓事业有成的人，大家也不要羡慕，稍有不慎他、她寿命就比你短了，这也是能量守恒的定律。你看到的​**既高又富还帅的**​，包括**很白且富还美的**，也大多是表象，所谓红颜薄命，也是有规律的。

![Image]()

# **【读书多的心机少】**

读书多的怎么会心机少的？​**这条争议最大**​，有人说读书人心机最重；有人说他们读书多，信了书本知识，这叫​**尽信书反而不如无书**​，实际中寸步难行，因为他们不懂人情世故。

究竟如何，应该两者兼而有之，各位自忖。不怕流氓多读书，就怕读书人耍流氓。

![Image]()

# **【心机多的安宁少】**

这也是，**“机关算尽太聪明，反误了卿卿性命”**，心机重心眼多的典型，就是王熙凤。

实际上，我们身边，无论什么组织、哪个家庭、何种社会，到处都少不了这样的王熙凤，他们就是喜欢玩心计。看起来一时得势，但长期来看，他、她有安宁不？

**自古心机婊，就没一个有好下场的，人生不得安宁**，死后也如此，甚至还被扒出来吊打。

最简单的，岳飞明明是好人，爱国英雄，大将军，但无论岳将军如何打胜仗，在奸臣秦桧那里来看，都是败仗，劣迹斑斑，这叫鸡蛋里面挑骨头。有道是“**青山有幸埋忠骨，白铁无辜铸佞臣**”，你去看西湖边岳王庙，这心机重的秦桧，已经被吊打了上千年，还会继续被唾弃上万年。

![Image]()

# **【劳累多的收入少】**

都承认，​**中国有的是人**​，所以，人人都能干的工作，这工资肯定不高，干活又累。

确实，这也是不争的事实。我看过一篇报道，贵州的矿山上，一个17岁的小伙子，将重达上百斤的矿石背出矿山，才收入1块钱，每天他最高的效率是背20个来回。这就是日薪20元，月薪勉强算作600块。你看看，这是多么辛苦的赚钱，多么少的收入，多么劳累的活？

你别身在福中不知福。但我们也要看到这只是现状，将来十年内，中国的人工会迅速提高。买个空调才千把块，叫人来修一下500；买瓶摩斯才20块钱，理个发对不起200；换个马桶800块，修下马桶你得给人家工时费吧，不多300，外加配件100块......

因此，​**劳累多的收入少，这是暂时现象**​，同时，你也要看下你这“劳累”有没有用错了地方。明知方向错误，你技术再好，将球踢进了自家的球门，那不是自摆乌龙嘛！这对你的事业和人生来说，是负的贡献。

![Image]()

# **【权力多的廉政少】**

这个就不必多言了，有权不用，过期是不是会作废？

你说你不贪，那是因为你没到时候，现在的你不贪，因为你还没成为苍蝇，你心里实际上坐着猛虎，你会装， 不说而已。

希望各部门包括我们各企业里的“贪官”，越来越少。

![Image]()

# **【情人多的精力少】**

情人多了，自然各种时间、睡眠和精力就都少了。

别人一处使劲，你多处押宝，不能集中精力，自然就是自身精力不够，且样样都不精了。

​**情人这里不仅仅指情人**​，也包括各种施力点、备胎，有人坚信备胎是好事，你多弄几个备胎试试看，​**累死你​**​。

![Image]()

# **【朋友多的困难少】**

这个也是常理，等你茕茕孑立之时，没人帮助你，你说这是什么原因？朋友太少。

落地生根，关键是你的社会关系和当地亲友圈子，生病不但没人照顾，还自己去开刀住院，​**没一个人来看你不要紧，都没人知道**​。

我们说一个地方宜居，年轻人总以为房价便宜就行，其实除了生活方便之外，更多的你还要社交方便啊！希望你以后改善。

![Image]()

# **【幽默多的郁闷少】**

我就喜欢蜡笔小新，小新比较幽默，也经常实话实说，​**不装**​。

你看你自己跟同事相处，你们经常讲“段子”不？多讲讲段子，互相埋汰，这才是真交。你们成天一起聊**​“今天天气不错”“明天可能要降温”“昨天有个新电影想去看看”......​**你说你们无聊到什么程度了，你们都不敢卸下自己的伪装，那不是做自己，你难受不？

幽默是一种生活情调，也不是说你不幽默就是白开水，​**幽默更是一种真实**​。你跟你的同事、领导、亲友包括父母在内，你想想看，你跟谁幽默过，你们才是真心的，这会减少郁闷。

反之，幽默少的郁闷多，也成立。

![Image]()

# **【笑声多的疾病少】**

笑一笑十年少，别成天板着个脸。你看那些​**苦瓜脸，谁谁都欠TA上千万的**​，回家之后也好不到哪里去。

男性也好女性也好，都这规律，管窥见豹。尤其是部分35岁的女领导，你别以为她就对你这年轻女下属不好，以为“女人为难女人”，不对，她就这性格，她对男下属也不好，回家还要管钱、管孩子、管老公，吓唬婆婆。当然，更多的是控制欲望极强的男人，家里外面，都听他的，一言堂，也从不苟言笑，这会伤身。

这就是个没有笑声的人生，她的他的人生自然疾病多。大家还年轻，到了40岁开外，你就知道心情可以影响至少10-20年的寿命了。你应该听过一个词语，叫做​**“郁郁而终”**​，板着脸，也是一种更大的病。

![Image]()

# **【旅游多的积蓄少】**

大家看下朋友圈，这个马尔代夫，那个巴厘岛，哪有这么多钱旅游的？

旅游自然伤钱，所以有人发明了“穷游”。

![Image]()

同时，你再去看看如下表的示例，你看存钱少的人，除了**喜欢买房的**双鱼座，其他省钱的星座，大多喜欢旅游，去普吉岛的，大多也是他们、她们。

![Image]()

# **【积蓄多的快乐少】**

不过，还有一种人，钱很多，就是舍不得花。**他、她每晚拿出存折和房产证，拿出来看一下，然后开心地睡觉。**

这种人，一开始我也不能理解，尤其是初中时学《吝啬鬼》，看《欧也妮葛朗台》，觉得这种临死前看到金元宝居然活过来的人，不可思议。现在40岁，经历过人间各种事情，各类人，各种各样的，终于明白了。**这种守财奴，实际上在我们身边有大把，比例还不低，十个里面至少有仨。**

守财奴就是喜欢金钱，他们此生自己也不怎么消受，就是喜欢钱，越多越好。比方一些贪官，贪得的财富，够他的家族10辈子也用不掉了，还在贪污，​**这不但是惯性，也是本性**​。也说明，“高薪养廉”执行的成本，可能行不通。

不过，他们不知道享受，​**“有财不外露”，就喜欢偷着乐**​。实际上，他们并不幸福，说起来“穷得只剩下了钱”，这是一种自私的贪婪而已，积蓄多的并不会快乐。

![Image]()

# **【去公园多的去医院少】**

这里的“去公园”，指出去健身，跑步，锻炼的意思。

最简单的，你看广场舞大妈，她们可比不跳广场舞的大妈，要来得长寿。身体是革命的本钱，身体也是长寿的本钱，你这只知道赚钱不懂锻炼，你赚了钱有身体去享受不？

去公园多的，自然去医院就少了，道理很简单。你回忆下自己上次体育锻炼，是不是还是在学校里的时候？那你完了，将来去医院会比较多。

![Image]()

# **【群里聊得多的烦恼少】**

这最后一句，是个玩笑话，群聊，无论QQ群、微信群，还是其他群，这已经成为我们日常的必经事项之一。你会在各种群里，成为群员，偶尔发表意见。

有个特点，那些发言多的，除了新人之外，还有就是善于发泄情绪的人。**现代人的情绪没有出口，现在对门的邻居都不认识，找不到人倾诉，群聊就是一个好地方。**

只要你是人，尤其职场人，你不在这个群里多发言，必定会在那个群里很活跃。这跟精神诉求是一个道理，女人爱说话，将平时的抱怨和不满都说掉了；男人不爱倾诉，烦恼和问题都自己背着，不说，偶尔几个通过喝酒和抽烟让之灰飞烟灭。其实没那么简单，体现到寿命上，就是男人平均寿命肯定短于女性。

男性体温高于女性，钙流失也比女性慢很多，包括性功能居然能维持到死亡的那一刻，女性性功能则大多在中年戛然而止，体力活等也是男性占优。但结果还是女性更长寿，这里​**跟精神上的情绪发泄有关**​，日常就是聊天的多少。群聊多的人，自然烦恼更少一点，他尤其是她，喜欢吐槽，实际上是减少烦恼的一种方法，还能延长寿命。

所以，这里劝你，​**多多参与聊天，无论是线下的，还是微信群聊**​。

好的，最后，我们完整欣赏一下这首诗，**经常拿出来读一遍，延年益寿**啊！

《你多我少》

> * 想法多的成事少，成事多的寿命少；

> * 劳累多的收入少，权力多的廉政少；
> * 情人多的精力少，朋友多的困难少；
> * 幽默多的郁闷少，笑声多的疾病少；
> * 旅游多的积蓄少，积蓄多的快乐少；
> * 去公园多的去医院少，群里聊得多的烦恼少。
