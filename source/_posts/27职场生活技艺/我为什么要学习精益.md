**2.个人体会：精益与常规生产的对比**

![Image]()

```
对比下精益生产和常规的批量生产，很直观的感受：
```

**​​ 2.1 有序与无序的对比。​**精益生产除了必须的标准在线库存（Standard WIP）之外，没有堆积 ，传统的大批量生产则可能到处是堆积，堆积除了意味着库存积压的浪费以外，还带来了搬运及搬运过程中造成的其他不良品的浪费。所谓的有序，你可以理解为目视上“一切井然有序”，有序必然意味着处于可控状态。就工作而言，可控状态比四处救火的混乱状态好的多。

**​2.2 问题的解决更为彻底。​**精益的五大原则是：价值,价值流,流动,拉动,完美，通俗的理解就是识别有价值的，通过拉动建立流动式生产，同时在过程中追求完美，丰田精益屋的两大支柱之一是Jidoka，理念就是发现问题主动停止下来，不管是机器主动停下来还是产线通过Andon系统手动停止下来，直到问题得到根本的解决。

**​2.3 L/T的减少。​**传统的各工站批量生产完毕后转移的方式，切换到精益“一片流”模式，交货周期大大减少，拿我经手的同一款铝压铸件来说，需要经过压铸、去毛刺、打磨、校形、CNC、清洗钝化、烘烤、全检、包装工序，两家供应商，同样200件PO，走传统批量生产的公司A在接到订单后，最快也要7天才可以交货，而用精益生产模式的供应商B在接到PO之后，第3天就可以交货了。L/T的缩短，对客供双方来说也意味的资金的快速周转，对企业运营来说，可以更高效的运营资金流，赚更多的钱。

**3.精益对我个人工作的影响或者帮助**

```
前面讲了那么多似乎与自己工作关系不是很大，这里站在个人工作相关的角度来谈下，精益对我个人工作的益处，我的日常工作大部分时间都是与供应商打交道，和供应商的关系是​**“大家好，才是真的好”**​。
```

![Image]()

```
日常的供应商稽核来讲，稽核从字面意思上就是检查并发现不合规的地方，目的是促进供应商改善提升其品控、生产运营，精益的精髓是消除浪费、增加价值，从过程方法上，精益为我做供应商稽核提供了更多视角，看问题的深度会更深一点。从某种程度上来讲，存在“八大浪费’的地方都是供应商稽核的问题点。

    从供应商辅导提升来讲，精益也给我带来了很多思路，同时提供了大量的改善工具，例如3G、标准化、均衡化、Jidoka、Poko-yoke、TQC、VSM、5Why、7Ways…….，如果可以在供方支持下建立“one piece flow“，那就更完美了。

   在审视供应商的改善成果/报告时，精益也给我提供了各种批判的角度和对比的方法，比如用5Why去审核其是否找到根本原因，用Poko-Yoke评估其改善方案是否彻底有效,现场、现物、现据也给审视改善证据及思路提供了很好的指导意见……
```

**4.精益思维**

```
以上讲的多是侧重于工具的作用，其实真正让我醍醐灌顶的是，某次听到我的客人，讲了一句​**“要有精益思维”**​，顿时觉得，这才是精益的精髓，利用工具只是比葫芦画瓢，要深入理解设计工具最初的目的，这就是意识层面的认知提升了，拥有精益思维时，就不必拘泥于必须在工作领域中某一个精益工具如何使用，甚至在生活中，做判断时顺理成章的信手拈来，且符合精益的理念，这才是在精益修行学习上臻入化境，乃吾辈努力的方向。
```
