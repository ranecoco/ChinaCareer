前言：本文主要讲述如何应对“三坑公司”逼套路员工自愿离职的手段。

**​     ​**​**​ ​2020年12月29号凌晨一点半**，拼多多公司23岁女员工下班路上猝死的新闻已经持续热搜一个星期。从宪法人权保护角度来看，并非只有拼多多公司，而是所有具备马老板所提倡的996福报公司，狼性文化公司，都对一个公民的健康权和生存权进行了严重的侵犯。厂长的观点，这种加班猝死，公司不仅要进行经济赔偿，该公司的法定代表人必须要负刑事责任。只要董事长在局子里关两天，相信肯定能多拯救几条鲜活的人命。

![Image]()

```
**​ ​劳动监察部门会象征性的对拼多多进行调查。**​​**本来就是迫于舆论压力，被动执法，如果能找到一个安抚舆论且表面合理的解释，对公众有个交代**​，对受害人家人多赔偿一点，再网络在对类似敏感词汇进行限流，相信再过1周，此事件就会被舆论淡忘。吃人血馒头的自媒体又会找到新的热点，博取流量和关注。

 **为何说劳动监察部门只会象征性的被动执法**，是因为我国目前要深化改革，扩大开放力度，2020年最后3天刚签定的中欧自由投资协定，以及未来一系列的贸易谈判等。国内企业竞争的压力会越来越大，国内企业的技术实力跟国外企业的差距还是非常明显的，即便是高科技公司，也是劳动密集型产业。假如欧美企业严格按照5天8小时工作，那么国内的996福报公司，大小周公司，狼性文化公司等，在时间成本上，人工成本上，管理成本上是远远低于国外公司，由此产生了相对的竞争优势。**相信这个现象至少还会持续10到15年。也就是有一代人要为复兴大业，为国内企业能跟国外企业站到同一起跑线上，付出大量的牺牲。**

  本文不过多讨论拼多多事件，只是提醒大家要明白，这就是目前国内打工人的现状，属于国家战略层面的东西，毕竟我们还是发展中国家，吃苦耐劳，艰苦奋斗，无私奉献才能让我们跟上国外老牌资本主义强国的步伐。
```

![Image]()

```
**大部分国内的企业由于缺乏核心技术，基本上赚取的都是通过降低成本带来的利润，也就是所谓的内卷化。大部分国内民营公司，明显的特点就是上坑客户，下坑供应商，中间坑员工的三坑公司。**

   ​**这种三坑公司在逼迫员工自愿离职，是有非常拙劣的套路的**​。为什么说是拙劣呢，是因为无论是这些公司的管理层，还是HR在劝退员工时，大多数使用的都是违法手段，通过**突然袭击，能坑则坑，能骗则骗，能蒙则蒙**的手段，来迫使刚入职场的小白，或者没有经历被劝退的员工，或者不懂劳动法的打工人。

  ​**这跟马保国的“闪电五连鞭”一个性质，都是自创的唬人的玩意**​，无论马保国信不信，只要看的人信了，把学费交了，那么他的目的也就达到了。三坑公司也一样，无论HR或者管理层，说的理由站得住站不住脚，是不是违法，只要打工人被唬住，签了因“个人原因”离职的申请单，那么公司的目的就达到了，零成本炒鱿鱼，没有比这更让资本家开心的事了。当然，你走之后，HR和管理层也会在背后，偷偷骂你SB。
```

![Image]()

```
但凡公司有合法且正当的理由辞退员工，是决然不会找员工谈判，甚至还要让你签“个人原因”离职，或者在背景调查，或者离职证明上给员工方便的。明显直接打印一份辞退通知书，效率更高一些。**不让你赔偿公司损失，不把你送进派出所，已经算是公司最大的仁慈。**

  **我们看一下在《劳动法》中，哪些条件下，公司不用给赔偿，可以直接开除员工，或者说直接解除劳动合同。**
```

> 第二十五条 劳动者有下列情形之一的，用人单位可以解除劳动合同：
> 
> (一)在试用期间被证明不符合录用条件的;
> 
> (二)严重违反劳动纪律或者用人单位规章制度的;
> 
> (三)严重失职，营私舞弊，对用人单位利益造成重大损害的;
> 
> (四)被依法追究刑事责任的。

```
**​​ ​​上述4条，是在劳动法里明确规定，公司可以不用任何赔偿就可以直接辞退员工。**当然，如果打工人违反了第三条：严重失职，营私舞弊，对用人单位利益造成重大损害的;或者第四条被依法追究刑事责任的。那是给我们打工人丢人，坚决剔除出打工人队伍。被开除，这没有什么好说的，该为自己的违法行为付出什么代价，就应该付出什么代价。

**​  公司最容易在第一条试用期，和第二条公司管理规章制度上做手脚，来恐吓打工人，迫使其自动离职。**
```

![Image]()

```
​**试用期最常用的手段是，故意把员工的绩效打的很低，以此来证明员工不符合录用条件，然后对员工劝退**​。实际上，由于公司试用期可以以合同工资的80%支付工资，很多公司，就是靠这个来降低公司成本的。还有一些公司在试用期不给员工缴纳五险一金，甚至转正前没有年假等等。

  很多刚入职场的小白，或者不懂劳动法的打工人，**很容易被领导和HR的说辞给唬住**。实际上，绩效低并不能直接证明打工人不符合录用条件，可以不用赔偿就辞退员工。如果进行劳动仲裁，或者法院审判时，公司必须要提供这个绩效设定合理，员工经过相应的岗位技能培训等，以及得到其他员工及工作相关人的证明后，才能认定该员工不符合录用条件。

  当然如果涉及简历造假，学历造假，证书造假等，在试用期被公司发现，认定不符合录用条件，那并不在本文讨论范围内。

 **​一般而言，绝大部分三坑公司，是无法严格证明打工人工作能力不符合录用条件的。​**在辞退员工时是要对员工进行赔偿的。也就是说公司属于无理由辞退员工，需要赔偿2N+1个月的平均月工资赔偿。

  试用期通常小于6个月，工作时间未满6个月，一般按半个月工资赔偿。因此理论上，试用期被辞退的员工是可以拿到**2个月工资赔偿**的。

  **另外，无论是已过试用期，还是未过试用期的打工人**。公司更常用的一个手段是收集打工人，日常违反劳动纪律或者用人单位规章制度的记录，然后以此来迫使打工人自愿离职。当然，人非圣贤孰能无过，尤其现在懒癌晚期的患者越来越多，迟到的事情似乎是家常便饭。公司还喜欢抓一些报销凭证的小问题等，不同的三坑公司虽然使用的手段不一样，但是本质都是一样的。
```

![Image]()

```
**​​  对付这种手段时，我们一定要注意第二法条的四个字，也就是“​**​**严重违反**​**​”。​**如果不构成严重违反，公司的因此辞退员工的理由是不成立。告诉大家一个小窍门，如果是严重违反的话，公司一般会直接开除，不会找打工人谈判。如果找打工人谈判，就说明，并不构成严重违反。

  ​**如果进行劳动仲裁，法院起诉时**​，公司不仅要证明员工经过了公司的劳动规章和管理条例的培训，同时也要提供员工确实严重违反了公司的劳动规章和管理条例的证据。

 ​**在提供这些证据的前提是**​，公司要先证明他们的劳动规章和管理条例是合法的。比如公司规定，无故旷工3日以上，属于严重违反公司管理制度，公司可以开除员工。这是合法的。

  **​如果公司规定，​**员工每天只能上厕所一次，一天上厕所三次属于严重违反公司管理制度。这就是不合法的管理制度，在法律上这属于无效条款。是不能开除员工的。

 **​ ​比如劳动法第41条规定 ​**
```

> 用人单位由于生产经营需要，经与工会和劳动者协商后可以延长工作时间，一般每日不得超过一小时;因特殊原因需要延长工作时间的，在保障劳动者身体健康的条件下延长工作时间每日不得超过三小时，但是每月不得超过三十六小时。

```
​**如果某些福报公司管理规章规定996的工作制，明显是违反劳动法的**​。以员工不遵守996工作制度来开除员工，是得不到法律支持的。

  **因此，大家入职后一定要仔细研读公司得管理制度和员工手册，不要在严重违反劳动规章和管理制度的作死边缘疯狂试探。**另外在公司以违反劳动规章和管理制度，迫使员工自愿离职时，一定要查清楚公司掌握了多少证据，哪些证据是构成严重违反的，哪些证据和制度是违法的。

**​ 在这种情况下，公司依然属于无正当理由辞退员工，还是可以要求赔偿2N+1的平均工资。**

  **难道真的天天处理劳动关系的HR和管理层，不知道自己哪些说辞是站的住脚的，哪些手段和规章制度是违法的吗？**
```

![Image]()

```
其实很少一部分公司的HR和管理层可能不懂法，确实不知道。但是大部分三坑公司的HR和管理层是揣着明白装糊涂。发挥着**能坑则坑，能骗则骗，能蒙则蒙，能拖则拖**的无奸不商的资本家精神，只要能少付打工人一块钱，对公司来讲都是赚到。所付出的成本和代价微乎其微，没见过哪个董事长或者高管因为劳动纠纷被判刑的。

 **​​ ​​因此大家要勇敢的使用劳动法来维护自身的合法权益，正义是自己主动争取来的。**另外再说一句，迟到的正义，就不是真正的正义。所以厂长非常厌恶那句“正义会迟到，但永远不会缺席”，如果正义都可以迟到，那么正义为何不会旷工呢？

  如果一个杀人犯，在犯罪后100年才得到正义的审判，难道对他的骨灰枪毙10分钟，也算是伸张了正义吗？

  **劳动法规定劳动仲裁诉讼有效期为1年，超过一年时间，正义就真的缺席了。**
```
